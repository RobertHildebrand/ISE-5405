# ISE 5405 — Optimization I: Interactive Lectures

Interactive HTML lecture decks for ISE 5405 (Virginia Tech). Live site:

**https://roberthildebrand.github.io/ISE-5405/**

Open `index.html` for the lecture list and presenting instructions (keyboard
shortcuts, pen/eraser annotation, whiteboards, PDF handout export, iPad use).

- Lectures 1–5: course intro, intro to linear optimization, proofs & LaTeX,
  and LP geometry I–II — with interactive widgets, checkpoint questions,
  and guided proof workshops.
- `figures/` — standalone offline interactive figures (graphical method,
  duality, sensitivity).
- `README_BUILDING.md` — how these decks are built (framework reference).

Built on the open textbook *Mathematical Programming and Operations Research*
and its [interactive visualizations](https://open-optimization.github.io/open-optimization-or-book/visualizations/).
