Polyhedra in Standard Form (§2.3)

\[P=\{x\in\mathbb{R}^n : Ax=b,\; x\ge 0\},\qquad A\in\mathbb{R}^{m\times n}\]
Standing assumption: the \(m\) rows of \(A\) are linearly independent (full row rank), so \(m\le n\).
Thm 2.5 (why it's harmless): if \(P\ne\emptyset\) and \(\operatorname{rank}(A)=ksame polyhedron. Redundant equations describe nothing new.
Counting intuition: \(Ax=b\) uses up \(m\) degrees of freedom, leaving an \((n-m)\)-dimensional world. Inside that world, only \(x\ge0\) constrains us. A corner needs the remaining \(n-m\) freedoms pinned — by that many \(x_i=0\).
That's the algebra we're about to make precise: corner = choice of which variables are allowed to be nonzero.

Basic Solutions in Standard Form (Thm 2.4)

Theorem. \(x\) is a basic solution of \(\{Ax=b,\,x\ge0\}\) \(\iff\) \(Ax=b\) and there are indices \(B(1),\dots,B(m)\) such that (a) columns \(A_{B(1)},\dots,A_{B(m)}\) are linearly independent, and (b) \(x_i=0\) for every \(i\notin\{B(1),\dots,B(m)\}\).
The recipe:
  1. Choose \(m\) linearly independent columns of \(A\) — the basis
  2. Set every other variable to zero (the nonbasic variables)
  3. Solve \(B x_B = b\) for the \(m\) basic variables: \(x_B=B^{-1}b\)
If the solved \(x_B\) comes out \(\ge 0\): a basic feasible solution. If some entry is negative: basic, but infeasible — a corner of the algebra, not of \(P\).
Terminology: \(B=[A_{B(1)}\cdots A_{B(m)}]\) is the basis matrix; the \(B(i)\) are basic indices.

Different bases → different corners. Singular choices → no basic solution at all. Negative entries → basic but infeasible. This one widget is the whole simplex data structure.

Degeneracy (§2.4)

Def. 2.10: a basic solution is degenerate if more than \(n\) constraints are active there.

Def. 2.11 (standard form): \(x\) is degenerate if more than \(n-m\) of its components are zero — i.e. some basic variable is zero too.
BT's example (\(n=3\)): \(x=(2,6,0)\) has exactly 3 active constraints — nondegenerate. \(x=(4,0,2)\) has 4 active — degenerate.
Why care? Several different bases can describe the same degenerate corner — algorithms can stall walking between them (Ch. 3's cycling problem!).

When Do Corners Exist? (§2.5)

Not every polyhedron has one — a halfplane in \(\mathbb{R}^2\) has no extreme point.

Def. 2.12: \(P\) contains a line if some \(x\in P\) and direction \(d\ne0\) satisfy \(x+\lambda d\in P\) for all \(\lambda\in\mathbb{R}\).
Theorem 2.6. For nonempty \(P=\{x: a_i'x\ge b_i\}\), equivalent:
  1. \(P\) has an extreme point
  2. \(P\) contains no line
  3. \(n\) of the vectors \(a_i\) are linearly independent
Cor. 2.2: nonempty bounded polyhedra and nonempty standard-form polyhedra always have a BFS. (Standard form: the constraints \(x_i \ge 0\) supply \(n\) independent vectors!)

Click-through: Extreme Point \(\Rightarrow\) No Line

\[\textbf{Claim: } \text{if } P \text{ has an extreme point } x^{ext}, \text{ then } P \text{ contains no line.}\]
\[\textbf{Assume not: } \exists\, \bar{x}\in P,\; d\ne 0:\;\; \bar{x}+\lambda d\in P\;\;\forall\lambda\in\mathbb{R}\]
\[x^{ext}+d\in P \qquad\text{and}\qquad x^{ext}-d\in P\]
\[x^{ext}=\tfrac12\,(x^{ext}+d)+\tfrac12\,(x^{ext}-d),\qquad x^{ext}\pm d\in P,\;\ne x^{ext}\]
\[\unicode{x21af}\;\; x^{ext}\text{ extreme}\qquad\Longrightarrow\qquad P \text{ contains no line}\quad\blacksquare\]

Optimality of Extreme Points (§2.6)

Thm 2.7. If \(P\) has an extreme point and the LP \(\min c'x\) over \(P\) has an optimal solution, then some optimal solution is an extreme point.
Thm 2.8 (stronger). If \(P\) has an extreme point, then either the optimal cost is \(-\infty\), or an extreme point is optimal.
Cor. 2.3 ⇒ Property 1. Every LP over a nonempty polyhedron either has cost \(-\infty\) or attains an optimal solution. No \(e^x\)-style pathologies — LP keeps the trichotomy exact.
the last touch is always a corner (or a whole edge — which includes corners)

\(c'y = c'z = v\). So what?
\(y,z\in Q\) — contradicting extremality of \(x^*\) in \(Q\) \(y=z\)

The Other Representation: Convex Hulls (§2.7)

Def. 2.5: a convex combination of \(x_1,\dots,x_k\) is \(\sum\lambda_i x_i\) with \(\lambda_i\ge0\), \(\sum\lambda_i=1\). The convex hull is the set of all of them.
Thm 2.9. A nonempty polytope is the convex hull of its extreme points. Two descriptions of one object: outside-in (inequalities) or inside-out (corners).
Both views get used: inequalities for feasibility checks, corner combinations for proofs and decompositions.
Drag the points — the polytope is whatever their hull is

Fourier–Motzkin: Solving by Shadows (§2.8)

Question: is \(P=\{x: Ax\ge b\}\) empty?

Projection: \(\Pi_{n-1}(P)\) = the shadow of \(P\) when you forget \(x_n\). Key fact: \(P\ne\emptyset \iff\) its shadow is nonempty.
  • Project away one variable at a time: \(\mathbb{R}^n \to \mathbb{R}^{n-1}\to\cdots\to\mathbb{R}\)
  • In \(\mathbb{R}\), emptiness is trivial to check: is some interval \([l,u]\) with \(l\le u\) left?
  • Thm 2.10: the eliminated system is the projection — so projections of polyhedra are polyhedra, and (Cor. 2.6) convex hulls of finite point sets are polyhedra too

The Elimination Step

To eliminate \(x_n\): sort constraints by the sign of \(x_n\)'s coefficient, normalize, and rewrite: \[\begin{aligned} x_n &\ge d_i+f_i'\bar{x} && i\in I^+ \quad(\text{lower bounds})\\ d_j+f_j'\bar{x} &\ge x_n && j\in I^- \quad(\text{upper bounds})\\ 0 &\ge d_k+f_k'\bar{x} && k\in I^0 \quad(x_n\text{ absent}) \end{aligned}\]
An \(x_n\) exists \(\iff\) every upper bound \(\ge\) every lower bound. So pair them up: for all \(i\in I^+, j\in I^-\) add \[d_j+f_j'\bar{x}\;\ge\;d_i+f_i'\bar{x}\] and keep the \(I^0\) rows. Done — \(x_n\) is gone.
Cost: removes \(|I^+|+|I^-|\) rows, adds \(|I^+|\cdot|I^-|\) — constraint counts can grow exponentially. Beautiful theory, terrible algorithm.
Why we teach it anyway: every derived inequality is a nonnegative combination of originals — the seed of Farkas' lemma and LP duality (Ch. 4). Remember this moment.

Click-through: Fourier–Motzkin in Action

\[\begin{aligned} &(1)\; -x_1\ge -1 \quad (2)\; -x_2\ge -1 \quad (3)\; -x_3\ge -1\\ &(4)\; -x_1-x_2\ge -3 \quad (5)\; -x_1-x_3\ge -3 \quad (6)\; -x_2-x_3\ge -3\\ &(7)\; x_1+x_2+x_3\ge 6 \end{aligned}\]
\[I^+=\{7\}:\; x_3\ge 6-x_1-x_2\qquad I^-=\{3,5,6\}:\; x_3\le 1,\; x_3\le 3-x_1,\; x_3\le 3-x_2\]
\[\begin{aligned} 6-x_1-x_2\le 1 &\;\Rightarrow\; x_1+x_2\ge 5\\ 6-x_1-x_2\le 3-x_1 &\;\Rightarrow\; x_2\ge 3\\ 6-x_1-x_2\le 3-x_2 &\;\Rightarrow\; x_1\ge 3 \end{aligned}\]
\[\text{carried over: } x_1\le 1 \qquad \text{derived: } x_1\ge 3 \qquad\Longrightarrow\qquad P=\emptyset\;\;\blacksquare\]

Why is LP Special? The Three Properties, Earned

Property 1. Every LP is infeasible, unbounded, or has an optimal solution — no in-between. (Cor. 2.3)
Property 2. Every local optimum is a global optimum — linear objectives over convex sets can't trap you.
Property 3. Nonempty polytope \(\Rightarrow\) an optimal solution sits at an extreme point. (Thm 2.7/2.8)
The simplex method's birth certificate: finitely many candidate corners (Cor. 2.1) + an edge structure to walk (adjacency) + a guarantee the best corner is globally best. All that's left is how to walk cleverly — Chapter 3.

Key Takeaways

  • Standard-form corners = bases: choose \(m\) independent columns, zero the rest, solve — feasibility decides BFS
  • Degeneracy: extra active constraints at a corner; many bases, one point; algorithmic headaches ahead
  • Existence (Thm 2.6): corners \(\iff\) no line inside \(\iff\) \(n\) independent constraint vectors
  • Optimality (Thm 2.7/2.8): searching corners is enough — Property 1 falls out as a corollary
  • Representations: inequalities or convex hull of corners; Fourier–Motzkin converts, projects, and foreshadows duality
