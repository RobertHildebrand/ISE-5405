Checkpoint questions pop up automatically at a few key slides in each deck (once per session) — a built-in pause to poll the class. Decks also remember where you left off.

Notes: Math is rendered with MathJax from a CDN, so an internet connection is needed. Each deck is a single self-contained HTML file — share them with students directly or post on Canvas; all interactive widgets work for self-study too. The URL hash (e.g. #12) tracks the slide, so you can resume where you left off.

Accessibility statement — these materials target WCAG 2.1 AA; press H in any deck for the screen-reader-friendly handout view.
