What is a Proof?

A logical argument that establishes the truth of a mathematical statement.

Built from:

  • Definitions — the precise meaning of every word we use
  • Axioms — the agreed starting points
  • Previously proved results — theorems, lemmas, corollaries
  • Rules of logic — how truths combine into new truths
In this course you will write proofs weekly. A proof is convincing writing for a skeptical (but fair) reader — your grader.

Logic Warm-up: Implication

Most statements we prove look like: \(P \implies Q\)  ("if \(P\), then \(Q\)")

Statement: \(P \implies Q\)
"If \(n\) is even, then \(n^2\) is even." ✓
Contrapositive: \(\neg Q \implies \neg P\)
"If \(n^2\) is odd, then \(n\) is odd."
Always equivalent to the original! ✓
Converse: \(Q \implies P\)
"If \(n^2\) is even, then \(n\) is even."
Not automatic — needs its own proof (true here, but logically separate).
Negation trap: the negation of "all \(x\) satisfy \(A\)" is "some \(x\) fails \(A\)" — not "no \(x\) satisfies \(A\)".

Mixing up converse and contrapositive is the #1 rookie proof error.

Think of \(P\Rightarrow Q\) as a promise: “whenever \(P\) holds, \(Q\) holds too.”
A proof of \(P\Rightarrow Q\) only needs to rule out one row: \(P\) true with \(Q\) false. That's why we may freely assume \(P\) and chase \(Q\).
Vacuous truth is why "every element of the empty set is purple" is true — and why edge cases in proofs (empty feasible sets!) need care, not panic.
Picture it

Implication is Containment

\(P \implies Q\) says: the set of things satisfying \(P\) sits inside the set satisfying \(Q\).
The contrapositive is the same picture read from outside: if you’re not in \(Q\), you can’t be in \(P\). Same fact, zero extra work.
The converse \(Q \implies P\) swaps the roles — a genuinely different statement, and here false: \(n=6\) is even but not divisible by 4. The gap between the ellipses is exactly where converse-counterexamples live.

Technique 1: Direct Proof

Idea: start from the assumptions; chain logical steps until the conclusion appears.

Claim. If \(n\) is even, then \(n^2\) is even.

Proof. Assume \(n\) is even, so \(n = 2k\) for some integer \(k\). Then \[n^2 = (2k)^2 = 4k^2 = 2\,(2k^2).\] Since \(2k^2\) is an integer, \(n^2\) is twice an integer — i.e. even. \(\;\blacksquare\)
Anatomy: unpack the definition ("even" = \(2k\)) → algebra → repack the definition. Most direct proofs are exactly this shape.

Technique 2: Proof by Contrapositive

Idea: to prove \(P \implies Q\), prove the equivalent \(\neg Q \implies \neg P\) instead.

Claim. If \(n^2\) is odd, then \(n\) is odd.

Proof. The contrapositive is: "if \(n\) is even, then \(n^2\) is even." We proved exactly that a moment ago. Hence the original claim holds. \(\;\blacksquare\)
When to reach for it: when \(\neg Q\) is easier to work with than \(P\) — e.g. "odd" is awkward, "even = \(2k\)" is friendly.

Technique 3: Proof by Contradiction

Idea: assume the statement is false; derive something impossible; conclude it must be true.
  • Powerful for non-existence and irrationality claims — where there is nothing to construct.
  • The whole argument runs inside a hypothetical world… which we then demolish.
In LP theory, constantly: “Suppose \(x^*\) were not optimal… then a better feasible point exists… contradiction.”

Technique 4: Proof by Induction

Idea: prove a statement for all \(n\in\mathbb{N}\) by setting up dominoes:
  1. Base case: the first domino falls (\(n=1\) holds).
  2. Inductive step: each falling domino knocks over the next (\(n=k\) true \(\Rightarrow\) \(n=k{+}1\) true).
Common bug: the step must work for every \(k\ge 1\) — check it doesn’t secretly need \(k\ge 2\).
Used here for: correctness of iterative algorithms (simplex pivots!), recursive structures, improving bounds.
base case + inductive step ⇒ they all fall

Click-through: \(\sum_{i=1}^n i = \frac{n(n+1)}{2}\)

\[S(n):\qquad \sum_{i=1}^n i \;=\; \frac{n(n+1)}{2}\]
\[\text{LHS}=1,\qquad \text{RHS}=\frac{1\cdot 2}{2}=1. \quad\checkmark\]
\[\textbf{Assume: } \sum_{i=1}^{k} i = \frac{k(k+1)}{2}\]
\[\sum_{i=1}^{k+1} i \;=\; \underbrace{\sum_{i=1}^{k} i}_{=\,k(k+1)/2} +\, (k+1) \;=\; \frac{k(k+1)}{2}+(k+1)\]
\[\frac{k(k+1)}{2}+(k+1)=\frac{(k+1)(k+2)}{2} \;=\;\text{RHS of } S(k+1)\qquad\blacksquare\]
Proof without words

Why \(1+2+\cdots+n = \frac{n(n+1)}{2}\)

n = 6
The sum \(1+2+\cdots+n\) is a staircase of blocks.
Take a second, flipped copy of the staircase… the two interlock into an \(n \times (n{+}1)\) rectangle.
So \(2\,(1+\cdots+n) = n(n+1)\) — divide by 2 and Gauss smiles. The induction proof verifies this; the picture explains it.

Disproving: One Counterexample Suffices

Idea: to disprove a claim about all \(n\), exhibit a single \(n\) where it fails.

Conjecture. For all integers \(n\ge 1\): \(\;n^2+n+41\) is prime.

  • Feels true: it holds for \(n=1,2,\dots,39\) — thirty-nine confirmations!

Proofs Meet LP: a First Optimization Proof

Claim. Let \(Z_{LP}\) be the optimal cost of the LP relaxation of a minimization ILP with optimal cost \(Z_{IP}\). Then \(Z_{LP}\le Z_{IP}\). Moreover, if the LP optimum \(x^*\) is integral, it is optimal for the ILP.
Proof. Every ILP-feasible point is also LP-feasible (dropping constraints only enlarges the feasible set). The minimum over a larger set can only be smaller or equal: \(Z_{LP}\le Z_{IP}\). Now suppose \(x^*\) solves the LP and is integral. Then \(x^*\) is ILP-feasible, so \(Z_{IP}\le c'x^* = Z_{LP}\). Combining both inequalities: \(Z_{IP}=Z_{LP}=c'x^*\), so \(x^*\) is ILP-optimal. \(\;\blacksquare\)
Two lines of logic, zero computation — and it's the foundation of branch-and-bound. This is what LP proofs feel like.

Part II — What is LaTeX?

  • A typesetting system built for mathematics, proofs, and scientific documents
  • Plain text + markup → professional PDFs
  • The standard in math, CS, engineering, and research
  • Required for all homework in this course
Why? Automatic numbering & references, beautiful equations, consistent formatting — and it makes you state things precisely.
This source… 
\sum_{i=1}^n i = \frac{n(n+1)}{2}
…renders as: \[\sum_{i=1}^n i = \frac{n(n+1)}{2}\]

Structure of a LaTeX Document

\documentclass{article}
\usepackage{amsmath, amssymb, amsthm}

\begin{document}

Hello! Inline math: $a^2+b^2=c^2$.

Display math:
\[
  \min\; c^\top x
  \quad\text{s.t.}\; Ax \ge b
\]

\end{document}
  • Preamble (before \begin{document}): class, packages, macros
  • Body: text, math, sections, figures
  • Inline math $...$ vs displayed math \[...\]
  • Comments start with % — the rest of the line is ignored
Recommended packages: amsmath, amssymb, amsfonts, bm, xcolor, graphicx, booktabs, hyperref

Displayed Math: equation vs align

One equation (numbered): 
\begin{equation}
  \min\; c^\top x
  \quad \text{s.t.}\; Ax \ge b
\end{equation}
Several aligned lines (amsmath) — align on &: 
\begin{align}
  Ax &= b \label{eq:cons}\\
  x  &\ge 0
\end{align}
  • align* or \nonumber to suppress numbering
  • Reference constraints with \eqref{eq:cons}
  • Scalable brackets: \left( ... \right), sets: \{x : Ax \le b\}
  • Symbols you'll need: \mathbb{R}, \mathbb{Z}, \le, \ge, \sum, \top, \forall, \exists
Rule of thumb: any derivation longer than one line goes in align with the relation symbols lined up.

Theorems & Proofs in LaTeX

% preamble: \usepackage{amsthm}
\newtheorem{theorem}{Theorem}
\newtheorem{lemma}{Lemma}

\begin{lemma}
If $n$ is even, then $n^2$ is even.
\end{lemma}

\begin{proof}
Write $n=2k$. Then
$n^2 = 4k^2 = 2(2k^2)$,
so $n^2$ is even.
\end{proof}
  • proof ends with an automatic QED box □
  • Custom macros save typing: 
    \newcommand{\R}{\mathbb{R}}
\newcommand{\vect}[1]{\mathbf{#1}}
    then $\R^n$ → \(\mathbb{R}^n\), $\vect{x}$ → \(\mathbf{x}\)
  • State the claim in a theorem/lemma block, then prove it — this is the expected homework format
