Completion Code Verifier

Instructor/TA tool — checks that a code matches the student's name. ← practice hub

Paste the student's name exactly as they entered it (Canvas roster name) and their code:

Code anatomy: ACTIVITY-SCORE-YYYYMMDD-CHECK. The check digits are a hash of activity + score + date + the student's (lowercased) name + a course salt. A shared code fails under any other name; an edited score or date also fails. This is participation-grade verification — spot-check a sample rather than every entry. Activities: CH = Corner Hunt, FF = Formulation Forge, PP = Proof Puzzles, DDNOT/DDSTA/DDVOC = drill decks.
